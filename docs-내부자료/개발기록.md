## 1. 이 앱이 무엇인가

도서관을 보면 옆의 QR을 찍어 앱의 그 도서관 화면으로 바로 들어온다.

- 앱 이름: **도서관 지도** (앱스토어 검색용 이름. 책 제목은 그대로 「전국 도서관 나들이」)

- 대상: 책을 든 사람, 나들이 갈 곳을 찾는 사람, 한국을 찾은 외국인(4개 언어)
- 원칙: **모르는 것은 지어내지 않는다.** 확인 못 한 운영시간은 비워 둔다.

## 2. 무엇으로 만들었나

- Expo SDK 57 · React Native 0.86 · expo-router (파일이 곧 화면)
- 상태: zustand + AsyncStorage (`library-outing-store`)
- 애니메이션: Reanimated (UI 스레드에서 도는 것만)
- 서버가 없다. 도서관 데이터는 **빌드할 때 JSON 으로 넣는다.**
  - API 키가 앱 안에 들어가지 않는다
  - 비행기 모드에서도 열린다
  - 대신 데이터를 고치면 앱을 다시 배포해야 한다

### 데이터가 합쳐지는 순서 (`src/data/libraries.mock.ts`)

```
씨앗(SEEDS: 이름·지역·특화·주제)
  + libraries.geocoded.json   좌표·주소·전화      (카카오)
  + libraries.enriched.json   정보나루 매칭        (정보나루)
  + libraries.standard.json   운영시간·휴관일·주소  (전국도서관표준데이터)
  + libraries.manual.json     손으로 확인한 값 (제일 세다)
  = MOCK_LIBRARIES
```

수집 명령은 README 참고. 요약하면:

| 명령 | 받는 것 | 키 |
|---|---|---|
| `npm run collect-hours` | 운영시간·휴관일·주소·전화 | 필요 없음 |
| `npm run geocode` | 좌표·주소·전화 | KAKAO_REST_KEY |
| `npm run collect-nearby` | 주변 카페·맛집·볼거리 | KAKAO_REST_KEY |
| `npm run enrich` | 정보나루 도서관 코드 | DATA4LIBRARY_KEY |
| `npm run collect-books` | 실제 대출 순위 | DATA4LIBRARY_KEY |
| `npm run collect-tour` | 주변 장소 사진 | DATA_GO_KR_KEY |
| `npm run collect-library-photos` | 도서관 실사진 | DATA_GO_KR_KEY |
| `npm run chat-ideas` | 달곰이 추천 칩 목록 | 필요 없음 |
| `npm run build-web` | QR 랜딩 페이지(docs/) | 필요 없음 |
| `npm run qr` | 인쇄용 QR 시트 | 필요 없음 |

> ⚠️ **도서관 목록을 바꾸면** `chat-ideas` → `build-web` → `qr` 를 다시 돌린다.
> 돌리지 않으면 칩이 없는 도서관을 권하거나, QR 이 없는 페이지로 간다.

## 4. 아이패드와 애플 기본 탭바

### 왜 바꿨나

처음엔 폰 화면을 아이패드에 그대로 늘려 썼다. 가로로 눕히면 화면 절반이 비고,
아래 떠 있는 탭바도 폰 모양 그대로였다. 그래서 두 번 고쳤다.

1. **우리가 만든 아이패드 배치** — 왼쪽 사이드바, 목록+상세 나란히, 접으면 위쪽 탭바
2. **애플 기본 탭바(NativeTabs)** — iOS 26 부터 진짜 Liquid Glass. 지금 iOS 기본값

### 지금 상태

- **iOS**: 애플 기본 탭바를 쓴다 (`src/hooks/useNativeTabs.ts`)
  - 아이폰: 유리 알약 + 검색은 오른쪽 동그란 단추(`role="search"`)
  - 아이패드: `sidebarAdaptable` 로 위쪽 탭바 ⇄ 사이드바
  - 마이 탭에서 끌 수 있고, **끈 선택은 저장된다** (기본이 켜짐이라 저장하지 않으면 되살아난다)
- **웹·안드로이드**: 우리가 그린 탭바(`LiquidTabBar`, `TabletNav`)를 계속 쓴다

### 애플 탭바에서 겪은 것과 해법

| 증상 | 원인 | 해법 |
|---|---|---|
| 상태 표시줄 자리만 회색(242,242,242) | 탭 컨테이너 기본색이 `systemBackground` | `unstable_nativeProps.nativeContainerStyle.backgroundColor` 로 직접 칠함 |
| 아이패드에서 화면 왼쪽이 사이드바 밑에 깔림 | 사이드바는 화면을 밀지 않고 위에 뜬다. 폭은 안전 영역으로만 알려 줌 | `TabScreen` 이 좌·우 안전 영역도 비움 |
| 달곰이 입력칸이 탭바에서 한참 뜸 | 화면 칸이 이미 탭바 위에서 끝나는데 우리가 탭바 높이를 또 더함 | 아래 안전 영역을 기기에게 묻고(`bottomEdge`), 여백은 16만 |
| 키보드가 입력칸을 가림 | KeyboardAvoidingView 가 부모 기준 y 와 화면 기준 y 를 섞어 잼 | 화면에서의 실제 위치를 재서 `keyboardVerticalOffset` 로 보정 |
| 마지막 말풍선이 잘림 | 대화 칸이 줄어드는데 보던 자리는 그대로 | 키보드가 올라온 뒤 맨 아래로 스크롤 |
| 뒤로가기에 「(tabs)」 | iOS 가 이전 화면 이름을 붙임 | `headerBackButtonDisplayMode: 'minimal'` |

## 5. 달곰이 (앱 안의 도우미)

`src/utils/assistant.ts` — **바깥 AI 를 부르지 않는다.** 앱에 든 데이터로만 답한다.
서버도 요금도 없고, 비행기 모드에서도 답하고, 무엇보다 없는 운영시간을 지어내지 않는다.

### 알아듣는 것

- 도서관 이름 (일부만 말해도, 지역명을 떼고 말해도)
- 주제 14가지 · 지역 14곳 · "지금 문 연"
- 운영시간 · 휴관일 · 전화 · 위치 · 인기 도서 · 주변 카페/맛집/볼거리
- 한국어·영어·일본어·중국어

### 추천 칩 (말풍선 아래 눌러 묻는 단추)

칩을 누르면 그 글자가 그대로 질문이 된다. 그래서 **권하는 문구에는 반드시 제대로 된
답이 나와야 한다.** 두 단계로 만든다.

1. 데이터에서 권할 수 있는 것을 모두 뽑는다 (운영시간이 있는 곳만 운영시간을…)
2. `npm run chat-ideas` 가 그 전부를 실제 달곰이에게 **4개 언어로 물어보고**,
   기대한 답이 나온 것만 `chat-ideas.generated.json` 에 적는다 (지금 1,041개)

앱은 적힌 것 중에서만 고른다. 목록이 비거나 깨지면 **예전 고정 문구로 돌아간다**(복구 장치).

칩은 늘 다섯 개 — **방금 이야기와 이어지는 둘 + 다른 추천 셋**.
질문할 때마다 새 씨앗을 뽑아 섞고, 이 대화에서 이미 물어본 것은 권하지 않는다.

### 검사가 찾아낸 진짜 버그들

칩을 검사하다가, 사람이 직접 물어도 틀리던 것들이 드러났다.

- 「농심식문화전문도서관 운영시간」 → 이름 속 '문화' 를 주변 볼거리로 읽었다
  → 무엇을 묻는지는 **도서관 이름을 지운 나머지 말**로 본다
- "Recommend Humanities libraries" → 과학 도서관이 나왔다 (`it` 이 Human**it**ies 에 걸림)
  → `\bit\b`, `\bai\b` 로 낱말 경계를 붙임
- "Food libraries" → 주변 맛집으로 알아들었다 → 뒤에 library 가 오면 주제로
- "Things to see near …" 를 못 알아들었다 → 문구 추가

## 6. 성능

탭을 누르면 멈칫하다 뚝 바뀌는 문제를 재서 고쳤다.

- 원인: 탭을 바꿀 때마다 검사 화면 전체(카드 132장 + 상세)가 다시 그려졌다.
  전환 효과는 그 일이 끝난 뒤에 시작하니, 멈춘 동안 효과가 다 지나갔다.
- 고친 것
  - 검색: 목록 칸(`ResultsPane`)과 상세(`LibraryDetail`)를 `memo` 로
  - 홈: 본문을 받는 값 없는 `memo` 로 분리
  - 앱이 켜진 뒤 나머지 탭을 하나씩 미리 만들어 둔다 (`router.prefetch`)
- 결과(개발 PC 기준): 검색 탭 복귀 시 다시 그리는 컴포넌트 **5,357개 → 162개**,
  0.159초 → 0.009초. 전환은 0.25초 크로스페이드로 30프레임 안팎.

## 8. 개발 환경과 자주 난 문제

맥북 프로(2019, 인텔) · Xcode 26.5 · 아이폰/아이패드 iOS 27 · 무료 Apple ID.

### 늘 쓰는 명령

```bash
cd ~/library-outing && git pull                      # 새 코드 받기
cd ~/library-outing && npx expo start --dev-client    # 개발 서버
cd ~/library-outing && npx expo run:ios --device      # 기기에 다시 설치
cd ~/library-outing && xed ios                        # Xcode 로 열기 (서명 문제 날 때)
```

### 겪은 문제와 해법

| 증상 | 원인 | 해법 |
|---|---|---|
| 「더 이상 사용할 수 없음」 | 무료 계정 서명은 **7일**이면 만료 | `npx expo run:ios --device` 로 재설치 |
| `No profiles for ...` 오류 | 터미널만으로는 무료 계정 프로필을 새로 못 받음 | `xed ios` → Xcode 에서 ▶︎ 한 번 실행 |
| 고친 게 기기에 반영이 안 됨 | 맥이 `git pull` 에서 막혀 있었다 (`expo run:ios` 가 `package.json` 을 고쳐 놓음) | 그 값을 저장소에도 반영해 충돌을 없앰 |
| 화면이 하얗게 뜸 | 개발 서버가 꼬임 | 서버를 껐다 `--clear` 로 다시 켜기 |
| 기기가 어느 코드인지 헷갈림 | — | 마이 탭 → **코드 표시** 줄 (고칠 때마다 손으로 바꾼다) |

### 데이터 수집할 때 조심할 것

- `collect-tour` 는 **기본이 랜드마크만** 돈다 (전부 하려면 `-- --all`).
  예전엔 그 결과로 파일을 통째로 덮어써서 94곳 사진이 사라졌다.
  지금은 **이번에 못 받은 곳은 지난 결과를 그대로 둔다.**
- 표준데이터는 값이 바뀔 수 있다. 2026-09-24 에는 광주·전남 주소가
  「전남광주통합특별시」로 내려와서 예전 표기로 되돌렸다.
  `collect-hours` 를 다시 돌리면 새 표기가 다시 들어온다.

## 9. 정한 것들 (왜 그렇게 했나)

- **주제는 도서관마다 하나.** 둘씩 달았더니 「어린이」를 눌렀는데 미술 도서관이 섞여
  나왔다. 두 번째 성격은 특화 문구에 글로 남긴다.
- **분류 이름에 부제를 붙이지 않는다.** 「음악·LP」로 찍었더니 LP 를 기대한 사람이
  "다른 게 섞였다"고 느꼈다. LP 는 음악 6곳 중 하나였다.
- **1곳짜리 분류는 만들지 않는다** — 필터로 쓸모가 없다.
  (법률만 예외로 먼저 자리를 만들었고, 지금은 2곳)
- **지역 이름은 옮기지 않는다.** 주소에 적힌 원문이고, 현지에서 길을 물을 때도 그 글자라야 통한다.
- **도서관 이름도 옮기지 않는다.** 영어로 바꾸면 달곰이가 못 찾는다.
- **사진은 저작권을 확인한 것만.** 공공누리 1·3유형만 쓰고 출처를 마이 탭에 모아 표시한다.
- **책이 먼저다.** 주제 분류가 책과 다르면 책을 따른다 (2026-09-25 서울·경기·인천 정리).

```bash
git revert <커밋>                                   # 그 변경만 취소
git reset --hard before-book-categories && git push -f origin main   # 표시해 둔 지점으로
```

표시(태그): `before-book-categories` = `a7151b3` (책 기준 분류 정리 직전)
