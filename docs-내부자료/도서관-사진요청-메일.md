# 도서관 사진 사용 요청 메일

앱에 실을 도서관 사진을 각 도서관에 요청할 때 쓰는 템플릿입니다.

## 보내기 전에

- **받는 곳**: 각 도서관 홈페이지의 "문의" 또는 대표 이메일.
  `src/data/libraries.*.json` 의 `homepage` 필드에 홈페이지 주소가 있습니다 (72곳).
  없는 곳은 지자체 통합도서관 사이트에서 찾으면 됩니다.
- **한 번에 여러 곳에 보낼 때는 반드시 개별 발송하거나 숨은참조(BCC)** 로 보내세요.
  받는사람 칸에 여러 기관을 나열하면 서로의 주소가 노출됩니다.
- 회신율을 높이려면 **앱 화면 캡처 1~2장을 첨부**하세요. "이런 앱에 이렇게 실린다"가
  보이면 훨씬 잘 응해 줍니다.

## 메일 본문

**제목:** [사진 사용 협조 요청] ○○도서관 소개 앱 「전국 도서관 나들이」

안녕하세요.

저는 ○○대학교 ○○학과 졸업작품으로 전국의 특화 도서관을 소개하는 모바일 앱
**「전국 도서관 나들이」** 를 개발하고 있는 학생 임○○ 입니다.

이 앱은 전국 132곳의 특화 도서관을 주제별로 소개하고, 이용자가 도서관을 찾아가
주변까지 함께 둘러볼 수 있도록 안내하는 것을 목표로 하고 있습니다.
○○도서관은 **○○ 특화** 도서관으로 선정하여 소개하고 있습니다.

다름이 아니라, 앱에서 도서관을 소개할 때 사용할 **외관 또는 내부 사진**을
제공해 주실 수 있는지 문의드립니다.

**요청 드리는 내용**

- 도서관 외관 또는 대표 공간 사진 **1~3장**
- 가로 방향, 가능하면 긴 변 1,200픽셀 이상
- 앱 내 도서관 소개 화면에 사용하며, **출처를 표기**하겠습니다

**사진 사용 범위**

- 사용처: 모바일 앱 「전국 도서관 나들이」의 해당 도서관 소개 화면
- 표기: 「사진 제공 : ○○도서관」
- 앱은 현재 졸업작품으로 개발 중이며, 추후 앱스토어 배포를 계획하고 있습니다.
  상업적 활용 범위에 제한이 있으시면 알려 주시면 그에 맞추어 사용하겠습니다.
- 제공하신 사진은 요청하시면 언제든 즉시 삭제하겠습니다.

혹시 제공이 어려우시더라도, **직접 방문하여 촬영한 사진의 게재가 가능한지**
알려주시면 감사하겠습니다.

바쁘신 중에 읽어주셔서 감사합니다.

## 회신을 받으면

1. 사진 파일을 `assets/libraries/{도서관id}.jpg` 로 저장
   (id 는 `src/data/libraries.mock.ts` 참고. 예: `seoul-library.jpg`)
2. `src/data/libraryPhotos.ts` 의 `PHOTOS` 에 한 줄 추가:

```ts
'seoul-library': {
  source: require('../../assets/libraries/seoul-library.jpg'),
  credit: '사진 제공 : 서울도서관',
},
```

3. 끝. 앱의 카드·상세 화면이 자동으로 실사진을 씁니다.

`credit` 을 채워 두면 나중에 [마이 > 사진 출처] 화면에 모아 표시할 수 있습니다.
(`photoCredits()` 함수가 이미 준비되어 있습니다)
